DEMONSTRATION

Variable Banner

Scroll this page. The large banner gradually becomes a compact sticky header and remains at the top.

How it works

The scroll distance is converted to a progress value from 0 to 1. Banner height, text size, image position, overlay strength, subtitle visibility, and navigation visibility are interpolated from that value.

Reusable configuration

Use the URL parameter ?page=home, ?page=services, or another configured page name. Each page can have its own title, subtitle, image, and accent text while sharing the same banner engine.

GitHub Pages

This project has no build step and uses only relative paths, making it suitable for a project site such as https://toptierpatentsearch.github.io/vari-banner/.

Google Sites

The page can be embedded by URL in Google Sites. For the most reliable viewport-wide sticky behavior, use it as a full-page embed or as a separately hosted page rather than trying to alter the native Google Sites header.

Scroll test area

Continue scrolling to confirm that the compact banner stays stationary at the top.

Patent-search projects often contain long technical sections, so a compact sticky header can preserve navigation without consuming excessive vertical space.

The implementation also honors reduced-motion preferences: users who request reduced motion receive a simpler state change instead of continuous animation.

You can replace the demonstration gradients with your own local image files or remote image URLs in script.js.

Additional navigation links can be added directly in index.html or generated from configuration if the project later becomes larger.

The banner is intentionally framework-free so it can be maintained easily with GitHub, Codex, or any text editor.
